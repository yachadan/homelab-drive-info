Privacy notice

Homelab Drive rclone is a private application operated by the owner of the Google account which authorises it.

Google Drive access

The application requests drive.readonly. It reads metadata to display folders, and file contents on demand when the owner opens a file. The owner also authorised importing four calendar ICS files into their private Nextcloud instance. This permission does not allow changing or deleting Drive files.

Storage and use

Access credentials are stored in protected configuration files on the owner's equipment. Folder listings are cached temporarily in memory; the browsing service limits its metadata cache to five minutes. The mounts do not maintain a persistent content cache or bulk mirror. On-demand reads transfer the selected file. Nextcloud retains calendar events, application metadata and small protected pre-import calendar recovery snapshots.

Data obtained through this connection is used for the owner's private file browsing and calendar functionality, not for advertising, sale, or model training. The application does not send Drive metadata to a third-party language model.

Control

The owner can stop the local service, remove its stored credentials, or revoke its access through their Google account's third-party connections settings. Future functionality requiring different permissions will require a separate authorisation.

This information site contains no application login, Drive listings or credentials. Its hosting provider may process ordinary web request logs.
