Homelab Drive rclone

A private, single-user connection between Google Drive and a personally operated homelab, using rclone.

The current configuration requests read-only Google Drive access (drive.readonly). It lists file and folder metadata and fetches file contents on demand when the owner opens a file in their private homelab. Four owner-selected calendar ICS files have also been imported into their private Nextcloud calendar. This connection cannot upload, edit or delete Drive files and does not bulk-mirror Drive.

This application is for its owner's personal use. It is not a public file-hosting or document-processing service.
